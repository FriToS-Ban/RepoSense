## Why

M4 and M5 found the same failure twice. Graph candidates carry real signal: pure PPR finds a third of the co-changed symbols with no text at all. But flat RRF cannot weigh them against lexical candidates, so every fused graph variant was at best level with lexical A, and below it at R@10. RRF sees only ranks. A learned ranker can use evidence that is comparable across channels.

## Method

- **Pool.** The union of the lexical (BM25F, the M6 configuration), structural 1-hop, PPR (top 80) and co-change candidate lists, about 140 candidates per query.
- **Features (26).** Each is computed for every candidate, whichever channel produced it:

  | Group | Features |
  |---|---|
  | lexical | normalised BM25F score, reciprocal lexical rank, generated-by-lexical flag, the candidate's name occurs on a changed line |
  | graph | 1-hop relation to a seed (8-way one-hot), relation score, reciprocal PPR rank, log PPR mass, reachable in two typed hops |
  | co-change | coupling confidence of the candidate's file with a changed file, log support |
  | node | test / method / class, private name, log size, log in-degree, same directory as a changed file, same top-level package |
- **Model.** Pointwise logistic regression with L2 on standardised features, fitted exactly by Newton's method (IRLS) in pure Python. Negatives are subsampled 20 per positive (seeded); uniform subsampling shifts only the intercept, not the ranking.
- **Training data.** T2-train only: 600 commits, the 100 qualifying commits per repository that precede T2-test's 50. Every training commit is older than every test commit. Co-change features use only history older than each training commit.
- **Model selection.** L2 ∈ {0.1, 1, 10, 100} by **leave-one-repo-out CV** on T2-train. The objective is the held-out recall of the top 40 (what packing receives), with nDCG@10 as the tie-break. The chosen L2 is refitted on all six training repositories. **T2-test is used once, for the final comparison.**
- **Variants**, to separate *graph as a candidate generator* from *graph as a ranking signal*:

  | Variant | Candidates from | Features |
  |---|---|---|
  | F | all channels | all |
  | F_nograph | all channels | no graph features |
  | F_lexpool | lexical only | all (graph features re-rank lexical candidates) |
  | F_lexonly | lexical only | lexical + node (a learned lexical reranker) |

A fifth variant, **F_nocc** (no co-change candidates or features), was added for deployment: production has no commit-history index (see M11).

## What this answers

1. **The graph does help, when it is a feature.** Holding the candidate pool fixed, graph features add .036 recall within budget and .052 nDCG@10. Holding the pool to lexical candidates only, they add .065 R@10. M4 and M5 could not see this because flat RRF had no way to weigh graph evidence against lexical evidence. Graph-as-generator adds little (+.018, n.s.): most co-changed symbols the graph reaches, BM25F also reaches. Where the graph helps is in deciding which of them matter.
2. **Learning by itself adds nothing.** A reranker restricted to lexical and node features (F_lexonly) equals A_tuned. The gain comes from the new evidence, not from the learner.
3. **Co-change history is redundant again** (F_nocc ≈ F), as in M4.
4. **Caveat: the learner absorbed T2's label biases.** The largest non-lexical weights are `same_dir` (+.53) and `is_test` (+.50), plus *negative* weights for callee relations. T2 judges tests heavily and never judges read-only callees (dataset card, biases 1 and 3). The gain is concentrated in tests (+.087, p_holm 4e-4); on `sym_code`, F is −.049 vs A_tuned (n.s., p .07). On T1, F_nocc's deps recall within budget (callees) is .772 against EA's 1.000. **A model trained only on history must not be deployed as-is for reviews.** M11 addresses this with an explicit rule, evaluated on all three benchmarks.

Weights of F (standardised; largest first): lex_score +.69, same_dir +.53, is_test +.50, fan-in −.47, lex_gen +.43, struct_score +.38, rel_callee −.21, two_hop +.20, cc_conf +.20, name_on_changed_line +.18, lex_rrank +.18, ppr_rrank +.18, rel_callee_on_changed_line −.17, ppr_log +.16.
